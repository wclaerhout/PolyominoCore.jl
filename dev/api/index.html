API

Exported names are listed without a prefix. The symmetry helpers are public but not exported; use them as PolyominoTools.canonical or bring them in with using PolyominoTools: canonical.

Type and construction

PolyominoTools.Polyomino — Type
Polyomino(cells)

A polyomino: a finite, non-empty, edge-connected set of unit cells (r, c) on the square grid. Rows grow upward and columns grow to the right, so (1, 1) is the bottom-left cell of the bounding box.

cells may be any collection of (r, c) tuples (a Set, a Vector, a generator); duplicates are ignored. The shape is normalized for translation (smallest row and column become 1), so == and hash compare shapes up to translation only. Use the symmetry keyword of PolyominoTools.canonical to also identify rotations or reflections. Throws if cells is empty or not connected.

source
PolyominoTools.coordinates — Function
coordinates(p) -> Vector{Tuple{Int,Int}}

The cells of p, normalized so the smallest row and column are 1, sorted lexicographically. Returns the stored vector without copying: do not mutate it.

source
PolyominoTools.parse_polyomino — Function
parse_polyomino(s) -> Polyomino

Build a Polyomino from an ASCII drawing. Exactly two grid characters:

  • # — a filled cell (block)
  • . — an empty cell (gap / cavity)

All whitespace is ignored, so source indentation and trailing spaces don't matter; use . (not spaces) for gaps. Columns are 1-based; the top text line is the top of the shape. Blank lines are dropped anywhere. Throws on an unknown character, an empty drawing, or a drawing whose filled cells are not connected (not a valid polyomino).

parse_polyomino("""
.#
##
""")            # an L-corner of 3 cells
source
PolyominoTools.@poly_str — Macro
poly"..." -> Polyomino

String-macro sugar for parse_polyomino. Use triple quotes for multi-row shapes:

t = poly"""
###
.#.
"""

PolyominoTools.is_connected — Function
is_connected(cells) -> Bool

True if cells (a collection of (r, c) tuples) forms one edge-connected (4-neighbour) blob. The empty collection is not connected. Flood fill: starting from one cell, keep adding unseen neighbours until none are left; the cells are connected if every cell was reached.

source
is_connected(p::Polyomino) -> Bool

Always true: the Polyomino constructor rejects cells that are not edge-connected, so every Polyomino is connected. This method exists so is_connected works on both polyominoes and plain cell collections (see the generic method).

Base.in — Method
cell in p

True if the cell (r, c) belongs to p, in p's normalized coordinates: the shape is shifted so its smallest row and column are 1, whatever cells it was built from.

julia> p = Polyomino([(5, 5), (5, 6)]);

julia> (1, 1) in p, (5, 5) in p
(true, false)

PolyominoTools.orientations — Function
orientations(p; symmetry = :translation) -> Vector{Polyomino}

All distinct orientations of p under symmetry, starting with p itself. :translation gives [p], :rotation up to 4, :full up to 8.

source
PolyominoTools.canonical — Function
canonical(p; symmetry = :translation) -> Polyomino

A fixed representative of p's equivalence class under symmetry: the orientation whose sorted coordinates are lexicographically smallest. Two polyominoes are equivalent iff their canonical forms are ==, so this is the key to use for Sets / Dicts.

source
PolyominoTools.is_equivalent — Function
is_equivalent(p, q; symmetry = :translation) -> Bool

True if p and q are the same shape under symmetry. With the default this is p == q.

source
PolyominoTools.symmetry_group — Function
symmetry_group(p) -> Vector{Symbol}

The symmetries of the square that map p onto itself (up to translation): a subgroup of the dihedral group D4, listed in the order

:identity, :rot90, :rot180, :rot270, :mirror_lr, :mirror_ud, :mirror_diag, :mirror_antidiag.

:rot90 is a quarter turn counter-clockwise (PolyominoTools.rotate90) and :mirror_lr the left-right mirror (PolyominoTools.reflect). The group has 8 ÷ length(orientations(p; symmetry = :full)) elements.

PolyominoTools.symmetry_group(poly"##") == [:identity, :rot180, :mirror_lr, :mirror_ud]
source

Enumeration

PolyominoTools.polyominoes — Function
polyominoes(n; symmetry = :translation) -> Vector{Polyomino}

All polyominoes with n cells, one per equivalence class under symmetry:

  • :translation: fixed polyominoes (OEIS A001168: 1, 2, 6, 19, 63, 216, …)
  • :rotation: one-sided polyominoes (A000988: 1, 1, 2, 7, 18, 60, …)
  • :full: free polyominoes (A000105: 1, 1, 2, 5, 12, 35, …)

Each class is represented by its PolyominoTools.canonical form, and the result is sorted by coordinates, so the output is deterministic.

Shapes are grown level by level: every n-omino is an (n-1)-omino plus one edge-adjacent cell. Memory grows with the number of shapes, which is fine up to about n = 12 (505,861 fixed 12-ominoes).

length(polyominoes(5; symmetry = :full))   # 12 free pentominoes

Properties

PolyominoTools.perimeter — Function
perimeter(p) -> Int

Number of unit edges on the boundary of p, including the edges around holes: 4·length(p) − 2·(number of edge-adjacent cell pairs). Every cell initially contributes 4 cells to the perimeter, but for each pair that is formed 2 edges are substracted.

perimeter(poly"##") == 6
source
PolyominoTools.nholes — Function
nholes(p) -> Int

Number of holes in p: 4-connected regions of empty cells that cannot reach the outside. Empty cells connect only through shared edges, so two filled cells touching at a corner separate the empty cells around them.

nholes(poly"""
###
#.#
###
""") == 1

Splitting

PolyominoTools.all_splits — Function
all_splits(p) -> Vector{Tuple{Polyomino,Polyomino}}

Enumerate every way to partition p into two non-empty connected polyominoes (A, B) with A ∪ B == p, A ∩ B == ∅. Each unordered split is returned once.

Adjacency of A and B is automatic: p is connected, so two connected pieces that partition it must touch. No other restriction applies; for example, a shape may be split into a ring and the piece that fills its hole.

source
PolyominoTools.unique_splits — Function
unique_splits(p; symmetry = :translation) -> Vector{Tuple{Polyomino,Polyomino,Int}}

Collapse all_splits(p) to unique unordered pairs of shapes, each tagged with its multiplicity: the number of distinct cuts of p that yield that same pair of shapes (compared up to translation by default). sum(m for (_,_,m) in unique_splits(p)) equals length(all_splits(p)).

With symmetry = :rotation (or :full) product shapes are additionally compared up to rotation (and reflection), so pairs that are rotated copies of each other merge and their multiplicities add. The returned representatives are the shapes as actually cut from p, in the order they first appear in all_splits(p).

source

Joining

PolyominoTools.attach — Function
attach(a, b, offset) -> Polyomino

The union of a and b shifted by offset = (dr, dc): cell (r, c) of b lands on (r + dr, c + dc) in a's coordinates (both as given by coordinates). Throws an ArgumentError if the two overlap or do not share an edge.

attach(poly"#", poly"#", (0, 1)) == poly"##"
source
PolyominoTools.attachments — Function
attachments(a, b; symmetry = :translation, placements = false)

Every distinct polyomino formed by placing b edge-adjacent to a without overlap. b may first be put in any orientation allowed by symmetry (see PolyominoTools.orientations); a stays fixed.

Results are distinct under symmetry: no two are equal after PolyominoTools.canonical(_; symmetry). Each class is represented by the first placement found, so each shape is a plus one copy of b (up to translation). The results are sorted by coordinates.

With placements = true, returns (shape, piece, offset) named tuples instead, where piece is the orientation of b that was used and attach(a, piece, offset) == shape.

Every result can be split back into a and b: all_splits(shape) contains the pair (up to translation, and up to symmetry for the b piece).

source

Plotting

These need a Makie backend, for example using CairoMakie.

PolyominoTools.visualize_polyomino — Function
visualize_polyomino(p::Polyomino; annotation = :none) -> Makie.Figure

Draw p as unit squares, oriented like the poly"..." drawing (rows grow upward).

annotation chooses what is drawn around the shape:

annotationdraws
:noneonly the shape (the default)
:gridthe shape on the cell grid of its bounding box
:fullthe grid plus axes labelled with the row r and column c of each cell, as in coordinates

Requires a Makie backend, e.g. using CairoMakie.

source
PolyominoTools.visualize_polyominoes — Function
visualize_polyominoes(ps::AbstractVector{Polyomino}; ncols = 2, annotation = :none) -> Makie.Figure

Draw several polyominoes in a grid with ncols columns, one panel per shape (titled by its index), all on shared axis limits so sizes are comparable. Shapes are oriented like visualize_polyomino, and annotation works the same way; the grid covers the largest bounding box among ps. Requires a Makie backend, e.g. using CairoMakie.
